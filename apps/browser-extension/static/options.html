What is counted and stored
  • Only removals Untrackable can confirm: parameters it removed from pages you open (it compares the requested and the sent address of each page load) and from links you copy with it.
  • Parameters left in place – protected links, your exceptions, while paused – are not counted. Removals the browser does not report may be missed. If another extension removes the very same parameters first, its removals can be counted too.
  • Stored on this device only: one number per day for the last 7 days and a total. No addresses, sites, parameter names or times. Turning statistics off deletes them.
  • Needs the browser permission to observe page loads (“webRequest”). It is used read-only and only while statistics are on; Untrackable never blocks or changes requests through it.

    Good to know

    • Sign-in, password-reset, payment and signed download links are detected heuristically and left unchanged. If a site still misbehaves, add it above or use “Open link without cleaning” in the link context menu.
    • Removing tracking parameters does not stop cookies, IP-based tracking or browser fingerprinting. Untrackable does not make you anonymous.
    • Right-click a link for “Copy link without query parameters” or “Open link without query parameters” to strip one link on purpose – in any mode, also where automatic cleaning would leave it alone.
    • Keyboard shortcut for “Copy clean link” can be changed at chrome://extensions/shortcuts.
