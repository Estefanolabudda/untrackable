# Untrackable 0.3.0 (public beta) – release notes

> **Beta.** This is the first public beta of Untrackable as an open-source
> project. It is published as a GitHub pre-release for manual installation
> (no automatic updates) and is not available in the Chrome Web Store. Please
> report problems through the issue templates – never paste real sign-in,
> payment or personal links – and security problems as described in
> [SECURITY.md](https://github.com/Estefanolabudda/untrackable/blob/main/SECURITY.md).

Clean stays the default mode. Existing settings are kept when you update from
0.1.0 or 0.2.0.

## New: redesigned popup and settings

- A status header with the main switch that always says what is happening:
  _On_, _Paused until …_ (with _Resume now_), _Paused in this tab_, _Not cleaned
  on this site_ or _Off_.
- A clear mode choice (Clean, Strict, Experimental) with a one-line
  explanation; Experimental is shown in amber and still needs an explicit
  confirmation.
- Real switches for "Never clean links to this site" and "Pause in this tab";
  long host names keep their domain visible.
- Light and dark themes, larger and sharper text (Chromium's extension pages
  previously shrank it), visible keyboard focus, screen-reader friendly names,
  high-contrast support, and a new icon.

## New: optional local statistics (off by default)

See how many **tracking parameters** Untrackable removed on this device –
today, in the last 7 days and in total.

- Off until you turn it on. Turning it on requests the optional, read-only
  `webRequest` permission; Chrome shows no additional warning for it.
- Only removals Untrackable can confirm are counted: page loads where the
  observed address change is exactly what Untrackable's rules remove, and
  links you copy with it. Incognito tabs are never counted.
- Only numbers are stored, on this device – no links, sites, parameter names
  or times of day. Nothing is ever sent anywhere.
- Turning statistics off (or removing the permission) deletes the numbers.
- It counts removed URL parameters; it is not a measure of trackers blocked.

Details: [docs/privacy/statistics.md](https://github.com/Estefanolabudda/untrackable/blob/main/docs/privacy/statistics.md).

## Safer Experimental mode

Experimental now also keeps the query of sign-in and payment hosts (for
example `login.`, `accounts.`, `pay.`, `checkout.`, `banking.`) and of OAuth
requests (`client_id`, `code_challenge`) and Microsoft device login. Clean
and Strict are unchanged.

## Under the hood

- A regression corpus of 259 sensitive real-world link shapes (sign-in,
  password reset, payment, signed downloads, banking/government) is checked in
  both engines and against the navigation rules.
- Settings carry a format version and are migrated conservatively; context
  menus are refreshed on every update. Upgrades from the published 0.1.0 and
  0.2.0 are tested automatically.
- The full browser test suite runs on Chrome for Testing 116 (the minimum)
  and a current stable release, in addition to Chromium.

## Known limitations (beta)

- Manual installation from GitHub Releases only; no automatic updates. To
  update, replace the folder contents and click reload in
  `chrome://extensions`.
- Tested automatically on Chromium, Chrome 116 and a current Chrome; manually
  on Chrome for macOS. Edge, Brave, Vivaldi and Opera are not tested.
- Protection of sign-in, payment and signed links is heuristic; Experimental
  will break some sites by design.
- Statistics can miss removals the browser does not report, and may count
  removals of another extension that removes the very same parameters first.
- Not an anonymity tool: cookies, IP-based tracking and fingerprinting are
  unaffected.

## Verification

- Automated: shared engine fixtures, unit and property tests (TypeScript and
  Rust), TypeScript-vs-Rust differential test, the sensitive-URL corpus,
  end-to-end tests in real Chromium/Chrome (including statistics in a real
  incognito window and upgrades from 0.1.0/0.2.0), dependency audits.
- Independent security, privacy, accessibility and design reviews; all
  confirmed findings fixed.
- Manual test by the maintainer on Chrome for macOS:
  [v0.3.0-beta-checklist.md](https://github.com/Estefanolabudda/untrackable/blob/main/docs/release/v0.3.0-beta-checklist.md).
