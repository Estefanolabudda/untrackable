# Untrackable 0.2.0 – release notes (draft)

> Draft. Not released: v0.2.0 needs the maintainer's macOS test and approval.

Available as a ZIP for manual installation (GitHub release asset); not
published in the Chrome Web Store.

## New: Experimental – strip query parameters

A fourth mode for maximum URL minimisation, explicitly chosen by you:

```
https://example.com/article?utm_source=email&id=123&ref=newsletter
                                       ↓
https://example.com/article
```

- Removes the **whole query string** – trackers, functional and unknown
  parameters alike. Scheme, host, path and fragment (`#…`) stay as they are.
- **Opt-in with a warning.** Selecting it asks for confirmation; while it is
  on, the popup and settings show **Back to Clean**. The badge shows `E`.
- **Still careful with what matters.** Links Untrackable recognises as
  sign-in, password reset, verification, invitation, payment, signed or
  expiring keep **all** their parameters – Experimental does not strip every
  query. It also protects names that matter when everything else goes (OAuth
  `code`/`state`, CSRF tokens, Stripe/PayPal/3-D Secure return parameters,
  `expires`, login redirects such as `return_to`, WS-Federation, German eID,
  Dropbox/Drive share keys, CDN tokens) and links that wrap another link
  (Outlook SafeLinks, Google/Facebook redirects). POST form submissions keep their
  query.
- **Expect breakage**: search results, filters, pagination and other site
  features that rely on query parameters will not work, and one-time links
  (password reset, magic links, payment returns) that Untrackable does not
  recognise may stop working. Use _Back to Clean_,
  a site exception, _Pause in this tab_ or _Open link without cleaning_.
- Copying a link with Cmd/Ctrl+C uses the Strict rules in Experimental –
  your clipboard never silently gets a stripped link. Use the context menu to
  strip a link on purpose.
- Newsletter click trackers whose target is hidden (`…/ls/click?upn=…`) stop
  working in Experimental; use _Open link without cleaning_.
- A link protected only because of a common name such as `code` keeps all
  its parameters, trackers included.
- Not an anonymity tool.

## New: context-menu actions

Right-click a link:

- **Copy link without query parameters**
- **Open link without query parameters**

They work in every mode and strip the query even of links that automatic
cleaning would protect – because you asked for it. Nothing happens
automatically, nothing is retried.

## Upgrading

Existing settings are kept; Clean stays the default. Downgrading to 0.1.0
turns Experimental into Clean.
