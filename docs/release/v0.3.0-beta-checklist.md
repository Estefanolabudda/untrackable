# v0.3.0 beta – release checklist

Status: **draft – not released.** Every step that changes the repository,
creates a tag or publishes needs the maintainer's explicit approval.

## Before the release

- [ ] PR #9 (redesign and statistics) merged after the maintainer's macOS test.
- [ ] CI green on `main` (all 7 jobs, including Chrome 116 and stable).
- [ ] Repository settings (see the public-repository security checklist):
      private vulnerability reporting on, `main` ruleset, fork-workflow
      approval, Dependabot alerts, secret scanning with push protection.
- [ ] Version bump in one PR: `apps/browser-extension/package.json` and
      `packages/core/package.json` to `0.3.0`, `CHANGELOG.md` `[Unreleased]` →
      `[0.3.0] – <date>`, release date in the release notes.
- [ ] Release notes reviewed: `docs/release/v0.3.0-release-notes.md`.

## Manual test on macOS (maintainer, separate Chrome profile)

- [ ] Fresh install from the release-candidate ZIP: popup and settings in
      light and dark mode; no text cut off, no scrollbar in the popup.
- [ ] Clean, Strict, Experimental (confirmation, _Back to Clean_) and Off.
- [ ] Statistics: off by default; turning on shows no permission dialog;
      counts a page load and a copy; reset; turning off deletes the numbers.
- [ ] Incognito (if allowed): links cleaned, nothing counted.
- [ ] Pause all, pause in this tab, site exception, long host names.
- [ ] Copy cleaning: Cmd+C, context menu, popup _Copy clean link_.
- [ ] Update test: load 0.2.0, configure, replace the folder with the
      candidate, reload – settings kept, five context-menu entries present.

## Release

- [ ] Annotated tag `v0.3.0` on the merge commit, created with the project
      identity (`docs/development.md`); the release workflow builds the ZIP and
      attaches `SHA256SUMS`.
- [ ] Check that the release workflow published it as a **pre-release** (the
      release notes carry the marker `<!-- release: prerelease -->`; the
      workflow passes `--prerelease`), and check its checksums.
- [ ] README: current release, ZIP name and SHA-256 (separate docs PR, as for
      v0.2.0).

## After the release

- [ ] Watch issues and security reports; fixes go into 0.3.x.
- [ ] Chrome Web Store preparation (listing texts, privacy-practices form,
      host-permission justification) – separate decision.
