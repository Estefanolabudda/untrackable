# Untrackable 0.1.0 – release notes (DRAFT)

> Draft for the maintainer. Not published. Tag, GitHub release and Chrome Web
> Store submission require explicit approval.

**Privacy by default. Zero friction.** Untrackable removes tracking
parameters from links – automatically, locally, without breaking sign-ins,
purchases or signed downloads.

## Highlights

- **Clean links while you browse.** `utm_*`, `fbclid`, `gclid`, `msclkid`,
  Mailchimp, HubSpot, Marketo, YouTube/Spotify `si` and more are removed
  before the request leaves your browser – also odd spellings like
  `Utm_Source`.
- **Clean links you copy.** Press Ctrl/Cmd+C on a link and you get the clean
  link. Or right-click → _Copy clean link_, or press Alt+Shift+U.
- **Never breaks what matters.** Sign-in (Google, Microsoft, Apple, GitHub,
  Okta, Auth0, SAML …), password reset, e-mail verification, unsubscribe
  pages, signed downloads and payment pages are left untouched.
- **You stay in control.** Clean (default) or Strict mode, pause for 15
  minutes, pause in one tab, never clean a site, or open a single link
  without cleaning.
- **Transparent.** The settings page shows exactly what would be removed from
  a link and why.
- **Private.** Everything happens on your device. No telemetry, no network
  requests, no browsing data stored.

## Installation

Chromium-based browsers 116+ (Chrome, Edge, Brave, Vivaldi, Opera; only
Chromium is tested automatically).

- From source: `npm ci && npm run build`, then _Load unpacked_
  `apps/browser-extension/dist` in `chrome://extensions` (Developer mode).
- From the CI artifact / release zip: unzip `untrackable-chromium-0.1.0.zip`
  and _Load unpacked_ the folder.

## Permissions

Chrome shows two warnings at install time:

- _Read and change all your data on all websites_ – needed so the browser can
  rewrite navigation URLs and so copy cleaning works on every page. The
  extension never reads page content beyond the link you copy.
- _Modify data you copy and paste_ – to put the clean link on the clipboard
  when you ask for it.

Optional, off by default: _webNavigation_ for the redirect-loop helper.

## Known limitations

- Not an anonymity tool: cookies, IP-based tracking and fingerprinting are
  unaffected.
- Protection of sign-in/payment/signed links is heuristic; use a site
  exception or _Open link without cleaning_ if a site misbehaves.
- While navigating: URLs with percent-encoded letters/digits in the path or a
  parameter name are left alone; Chromium may write a valueless parameter as
  `edit=`; mixed-case trackers in URLs with 7+ parameters are only cleaned
  when copying; only top-level page loads are cleaned.
- Copy cleaning works with the keyboard shortcut only (not the Edit menu),
  for a selection that is exactly one link; not in iframes or shadow-DOM
  inputs; the clean link is written right after the copy as plain text.
- Redirect-based click trackers (`tracker.example/click?u=…`) are not
  unwrapped yet.
